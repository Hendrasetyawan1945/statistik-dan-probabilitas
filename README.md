# Statistik dan Probabilitas

Folder ini digunakan untuk menyimpan materi, catatan, dataset, script analisis, serta tugas terkait mata kuliah/topik **Statistik dan Probabilitas**.

---

## 📁 Rekomendasi Struktur Folder

Anda dapat mengorganisir isi folder ini sesuai kebutuhan, misalnya:

- `materi/` : Materi perkuliahan, modul, slide presentasi, atau ringkasan teori.
- `dataset/` : File data mentah maupun olahan (`.csv`, `.xlsx`, `.json`, `.sql`).
- `praktikum/` : Script atau kode analisis (Python / Jupyter Notebook, R, PHP, dsb.).
- `tugas/` : Latihan soal, tugas mandiri/kelompok, dan laporan.

---

## 📌 Topik Utama yang Dicakup

1. **Statistika Deskriptif**:
   - Ukuran Pemusatan Data (*Mean, Median, Modus*)
   - Ukuran Penyebaran Data (*Jangkauan, Variansi, Standar Deviasi, Kuartil, IQR*)
   - Visualisasi Data (*Histogram, Boxplot, Scatter Plot*)

2. **Teori Probabilitas**:
   - Ruang Sampel dan Titik Sampel
   - Kaidah Penjumlahan dan Perkalian
   - Probabilitas Bersyarat & Teorema Bayes

3. **Distribusi Probabilitas**:
   - Distribusi Diskrit (*Binomial, Poisson, Hipergeometrik*)
   - Distribusi Kontinu (*Normal/Gaussian, T-Student, Chi-Square, F-Distribution*)

4. **Statistika Inferensial**:
   - Estimasi Parameter dan Interval Kepercayaan (*Confidence Interval*)
   - Uji Hipotesis (*t-test, ANOVA, Chi-Square test*)
   - Analisis Regresi & Korelasi Linier
